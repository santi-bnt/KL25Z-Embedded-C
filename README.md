# KL25Z Embedded C

This repository contains practices and projects developed for the **FRDM-KL25Z** board, as well as computer architecture exercises written in **Verilog**.

The embedded section uses C programming to work with GPIO, ADC, PWM, LCDs, matrix keypads, interrupts, and FreeRTOS.

The Verilog section contains educational RISC-V-style processors: single-cycle, pipeline, and a mini multicycle architecture for the exam.

## Practices

The `Practices` folder contains exercises for the **FRDM-KL25Z** board.

| Folder | Description |
|---|---|
| `Practice1` | RGB LED control using a matrix keypad and LCD. |
| `Practice1_FreeRTOS` | First versions using FreeRTOS tasks. |
| `Practice2_FreeRTOS` | FreeRTOS with queues, mutexes, semaphores, and interrupts. |
| `Practice3` | Practice with keypad, LCD, timers, and interrupts. |
| `Practice4` | Running/paused state control using interrupts. |
| `Practice_potenciometer` | Potentiometer reading using ADC. |
| `Practice_temperature` | Temperature sensor reading with LCD output. |
| `prac_pwm` | LCD, keypad, ADC, interrupts, and PWM integration. |

## Exam

The `Examen` folder contains the **RV-Mini Multicycle** architecture.

This architecture uses:

```text
24-bit instructions
16 registers from R0 to R15
FSM-based control unit
ALU reused across multiple cycles
load, store, jump, add, sub, and, addi, beq
```

It also includes design images in:

```text
Examen/images/
```

## Useful Commands

### Run Exam With Icarus Verilog

From the `Examen` folder:

```cmd
iverilog -o mini_multicycle.out main_tb.v main.v PC.v Instruction_memory.v RF.v Extend.v Control_unit.v ALU.v Data_mem.v
vvp mini_multicycle.out
```

### Run Single-Cycle

From `verilog/single_cycle`:

```cmd
iverilog -o single_cycle_cpu main_tb.v main.v PC.v Instruction_memory.v RF.v Extend.v Control_unit.v main_decoder.v ALU_decoder.v ALU.v Data_mem.v mux.v mux3.v adder.v branch_comparator.v
vvp single_cycle_cpu
```

### Run Pipeline

From `verilog/pipe_line`:

```cmd
iverilog -o pipeline_cpu main_tb.v main.v IF_stage.v ID_stage.v EX_stage.v MEM_stage.v WB_stage.v HazardUnit.v Instruction_memory.v PC.v RF.v Extend.v Control_unit.v main_decoder.v ALU_decoder.v ALU.v Data_mem.v mux.v mux3.v adder.v branch_comparator.v
vvp pipeline_cpu
```
